# statistics-data-analysis

统计与数据分析课程学习笔记仓库。

> 用 Git 管理学习笔记：每次学完一个主题，就在 `notes/` 里新增一篇笔记，commit 并 push，留下完整的学习轨迹。

## 学习计划

| 阶段 | 主题 | 状态 |
|------|------|------|
| 1 | 描述性统计：均值、中位数、方差、分位数 | ✅ 已开始 |
| 2 | 数据可视化：直方图、箱线图、散点图 | ⬜ 未开始 |
| 3 | 概率基础：随机变量、常见分布 | ⬜ 未开始 |
| 4 | 参数估计与置信区间 | ⬜ 未开始 |
| 5 | 假设检验：t 检验、卡方检验 | ⬜ 未开始 |
| 6 | 相关与回归：线性回归入门 | ⬜ 未开始 |
