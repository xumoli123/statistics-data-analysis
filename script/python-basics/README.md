# Python 核心语法学习资料

面向零基础学习者，每个主题一个 `.py` 脚本文件，带中文讲解注释、可运行示例和练习题（附参考答案）。建议按编号顺序在 VSCode 中逐个打开、阅读注释、直接运行（点击右上角 ▶ 或在终端执行 `python 01_variables.py`），然后动手做练习。

## 学习顺序

| 顺序 | 文件 | 主题 | 核心内容 |
|------|------|------|----------|
| 1 | `01_variables.py` | 变量 | 赋值与重新赋值、命名规则、基本数据类型（int/float/str/bool）、动态类型、多重赋值与交换、f-string 初体验 |
| 2 | `02_operators.py` | 运算符 | 算术（重点：`/` vs `//`、`%`）、比较、逻辑（含短路特性）、赋值、成员 `in`、身份 `is` vs `==`、优先级 |
| 3 | `03_expressions.py` | 表达式 | 表达式 vs 语句、四类表达式、求值顺序、三元表达式、链式比较、f-string 中的表达式 |
| 4 | `04_flow_control.py` | 流程控制 | 缩进即语法、if/elif/else、while、for + range、break/continue、循环 else、九九乘法表 |
| 5 | `05_functions.py` | 函数 | 定义与调用、参数、返回值、作用域、docstring、内置函数速览、类型提示、递归初体验 |

## 使用建议

1. **先读后跑**：先从头读一遍注释和代码，再整体运行看输出。
2. **改着玩**：随便改数值、改字符串，观察输出变化——这是学习语法最快的方式。
3. **做练习**：每个文件末尾有 3~4 道练习题（注释块），自己写完后，再对照文件底部的"参考答案"。
4. **小步提交**：做完一个主题，可以在 VSCode 终端运行 `python -m doctest` 之外，还可以尝试把练习提交到你的 Git 仓库存档。

## 运行环境

- Python 3.10+（推荐 3.13）。若终端中文输出乱码，可先执行 `set PYTHONUTF8=1`（CMD）或 `$env:PYTHONUTF8=1`（PowerShell）。
- VSCode 推荐扩展：Python（Microsoft）。
